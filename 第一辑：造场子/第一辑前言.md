# 第一辑前言：造场子

本书把 AI Infra 的完整链路分成三辑。第一辑讲造场子，也就是智算中心的物理底座和基础硬件。

很多人讨论大模型时，喜欢从算法、框架、算力聊起。但真到了要建设一个能跑训练、能推理的集群时，第一步往往不是选 GPU，而是找一块能供得起电、散得了热、铺得开网络的地方。

智算中心和传统数据中心不是同一个物种。同样大小的机柜，传统 CPU 机房放十几台服务器，功耗不过几千瓦；GPU 机房放几台训练节点，功耗就能到几十千瓦。空气散热在 CPU 时代够用，到了 GPU 时代就要碰物理天花板。光模块从温热变成烫手，风扇从辅助变成核心设备，供电从单相 220 伏变成三相 380 伏。

这些变化意味着，AI Infra 工程师不能只懂软件。你要理解电力、制冷、机柜布局、光纤长度，因为这些会直接影响后面的网络性能、训练稳定性和运营成本。

第一辑的三章分别讲：

- IDC 与智算中心建设：电力、散热、选址、物理部署的约束
- GPU 集群硬件选型与交付：训练卡、推理卡、国产 GPU 怎么选，到货后怎么验收
- 智算网络与 RDMA/RoCEv2：为什么普通以太网不够，RDMA 和 RoCEv2 怎么支撑分布式训练

这三章是基础，后面讲的 Kubernetes、Volcano、训练通信、推理部署，都建立在这个底座之上。底座不稳，上层再精巧也跑不顺。
